# matrix-selection

The keyed matrix (`observable_matrix.hpp`) and its table model (`matrix_table_model.hpp`), M rows; the selection tracker and the
models that host it (`selection_tracker.hpp`), S rows. Tests are in `tests/qt/edge/`: `capability_edge_matrix_contract`,
`capability_edge_matrix_reentrancy` (built twice, with and without debug assertions) and `capability_edge_matrix_lifetime`.
QAbstractItemModelTester runs in fatal mode on every model. No QTBUG id is cited: the cases come from the matrix contract
and from the Qt documentation of the model signals.
