# proxies-selection

Sort and filter proxies, the other proxy models, and the selection model, over the list and table models of the
observable containers. Tests are in `tests/qt/edge/`: `capability_edge_proxy_sort_filter`, `_filter`, `_other`,
`_selection` and `_random`. QAbstractItemModelTester runs in fatal mode on every model and proxy. Where Qt has a model
of its own that does the same (QStringListModel, QStandardItemModel), the selection tests compare the container
model with it, signal by signal, so Qt is the reference. No QTBUG id is cited: the cases came from the class
documentation and from Qt's own proxy and selection tests, and none of them failed here.
